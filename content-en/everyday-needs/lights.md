## Starting with a Lamp
A lamp connected to a supported smart plug is a clear first step. Test its manual operation and then set up [evening lighting](/guides/evening-lamp/).

## Motion-Activated Lighting
A sensor can turn on the hallway light. When setting up the automation, also consider turning the light off and whether the light should only react in the dark. The turn-off time also depends on the specific sensor's behaviour.

## Bedside Button
A supported wireless button can control selected lights. This is also useful for household members who do not want to use a mobile device.

## Before You Buy
A smart bulb requires power. If you disconnect it using a standard switch, Home Assistant will not be able to control it. Consider how the whole family will use it.
