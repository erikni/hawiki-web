## A home that helps you

Home Assistant is software that brings supported smart devices together. You can control them from one place and create automations that let them work together.

For example, a button by the door can turn off several lights. A leak sensor under a washing machine can notify you when it detects water.

## Three things worth knowing

- Home Assistant runs on a device that remains powered on in your home.
- Check that a specific model is supported before buying it.
- Some devices work locally, while others need an internet connection and the manufacturer's cloud service.

## Do I need to know how to code?

You can create many common automations through the user interface. Connecting and maintaining devices still takes some time. Start with one device and one useful task.

## Will it work without the internet?

Local control can keep working while your home network and Home Assistant are running. Devices that depend on a manufacturer's cloud service may be limited. During a power cut, operation depends on backup power.
